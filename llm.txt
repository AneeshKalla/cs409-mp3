Atlas is MongoDB’s cloud database hosting service. It runs your database on MongoDB-managed servers so you don’t have to install and maintain a database server yourself.

In your project:
- Atlas stores your users and tasks.
- Render runs your Node/Express API.
- Your API uses the connection string to log into Atlas and read or update that data.
For example: someone creates a task → Render receives the request → your API saves the task in Atlas.
